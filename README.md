# Crypto Price Tracker

Real-time cryptocurrency price tracker using Binance API

## Features
- Search any trading pair (BTCUSDT, ETHUSDT, etc.)
- Real-time price data from Binance
- Error handling for invalid symbols

## Technologies
- React
- Binance API
- CSS3

## Installation
```bash
npm install
npm run dev

Usage

Enter a trading pair symbol (e.g., BTt the current price.

API

Uses Binance public API endpoint:
https://api.binance.com/api/v3/ticker/price
